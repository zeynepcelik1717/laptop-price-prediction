## 📌 Project Overview

This project was developed as an end-to-end machine learning web application.

The system allows users to select laptop specifications such as:

- Company
- Product
- Type
- RAM
- CPU
- GPU
- Memory
- Operating System
- Screen Resolution
- Weight
- Screen Size

and predicts the estimated laptop price in Euros.

The application includes:

- Machine Learning model training
- Data preprocessing
- Dynamic filtering system
- Responsive frontend design
- FastAPI backend
- Live deployment with Render

---

## 🧠 Machine Learning
